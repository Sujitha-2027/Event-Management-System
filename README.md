# Event Management System

## About the Project

Event Management System is a Python and MySQL based project used to manage events and participants.

## Features

- Add Event
- View Events
- Update Event
- Delete Event
- Add Participant
- View Participants
- Update Participant
- Delete Participant

## Technologies Used

- Python
- MySQL
- mysql-connector-python

## Database

Database Name:
event_management

Tables:
- events
- participants

## How to Run

1. Install Python
2. Install MySQL
3. Create the database and tables
4. Install mysql-connector-python

```bash
pip install mysql-connector-python
